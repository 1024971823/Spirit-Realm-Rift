# Prism Breach（棱镜突破）— RoboMaster 战术竞技场

一款基于 **Three.js + React + Express + WebSocket** 构建的多人 3D 机甲大师（RoboMaster）战术激光竞技游戏。玩家将作为机甲编队的一员，在 **RM-S1 突击手** 与 **RM-EP 工程机器人** 之间自由切换协同作战：采集矿脉获取全队经济、购买弹药与维修补给、破坏能量掩体并躲避动态场地危害，在职业联赛风格的反应堆竞技场中争夺胜利。

---

## 核心特性

### 1. 双机甲协同体系（开源 URDF / COLLADA 3D 模型）
- **RM-S1 突击手（Assault Striker）**
  - 搭载双轴云台激光发射器与全向麦克纳姆轮底盘（100 装甲 / 50 护盾）。
  - 专属技能 **超频过载 `[E]`**：短时间内提升射速并瞬间清空热量。
  - 消耗团队共享经济实时购买弹药补给与维修包（`[B]` 快捷购弹或 `[1][2][3]` 指定补给）。
- **RM-EP 工程机器人（Unarmed Engineer）**
  - 重装甲机械臂工程底盘（135 装甲 / 75 护盾），**设定为无武装单位，无法发射子弹**。
  - 采矿效率高达 **3 倍（36 积分/秒）**，负责为全队赚取弹药经济。
  - 专属技能 **涡轮采矿脉冲 `[E]`**：短时间内采矿翻倍并为周围友军恢复护盾。
- 按 `[U]` 可随时在 **S1 / EP** 之间切换出战单位。

### 2. 团队经济与矿脉采集循环
- 场地内分布多处标准矿脉与高产富矿脉，矿脉采空后会自动进入冷却再生。
- 靠近矿脉长按 `[E]`（EP 工程车也可按住鼠标左键）即可建立采矿激光链路，将矿石转化为全队共享的团队积分。

### 3. 全模型物理与弹道碰撞箱
- 场地内所有模型（四周护墙、立柱、高台斜坡、中央地标、可破坏能量掩体、矿脉晶簇、危险装置底座）均配备统一的物理与射线碰撞箱。
- 机甲之间具备实体防穿模碰撞；弹道命中判定基于 **有向包围盒（OBB）** 精准覆盖 S1 底盘/云台与 EP 底盘/机械臂结构。
- 遵循机甲底盘设定：**机器人不可跳跃**，可通过阶梯斜坡平稳行驶至高台。

### 4. 动态竞技场与多人联机系统
- **两张战术地图**：`反应堆铸造厂（Reactor Foundry）` 与 `极寒中继站（Cryo Relay）`。
- **三种竞技模式**：团队激光对抗（3v3）、核心争夺（区域控制）、个人自由混战（FFA）。
- **动态环境交互**：可破坏充能护盾墙、周期性预警并激活的等离子电弧塔、中央旋转扫描激光及极寒冷却液泄口。
- **服务器权威架构（20Hz）**：服务端负责物理校验、防作弊限速与视线检测、智能 AI 机甲补位、SBMM 技术分级匹配、私人房间邀请码、好友列表以及基于 WebRTC 的小队/队伍/近距离语音通讯。

### 5. 军械库、成长与中英双语
- **军械库与涂装**：包含多种激光发射器（脉冲卡宾、棱镜磁轨炮、散射棱镜炮）、战术模块 `[Q]`（相位推进器、宙斯盾脉冲护盾、电弧干扰脉冲）以及随 XP 解锁的光束光谱、装甲涂装与操作手徽章。
- **中英文双语切换**：支持主界面右上角、设置面板及暂停菜单随时一键切换 `中文 / EN`，自动持久化至本地存储。

## 操作指南

| 操作 | 键鼠按键 | 手柄按键 | 说明 |
| :--- | :--- | :--- | :--- |
| 底盘移动 | `W` `A` `S` `D` | 左摇杆 | 全向麦克纳姆轮移动（不可跳跃） |
| 云台瞄准 | 鼠标移动 | 右摇杆 | 丝滑第三人称越肩视角瞄准 |
| 射击 / EP 采矿 | 鼠标左键 (`LMB`) | `RT` | S1 发射激光；EP 靠近矿脉时自动采矿 |
| 精确瞄准 (ADS) | 鼠标右键 (`RMB`) | `LT` | 拉近视野提升瞄准精度 |
| 推进冲刺 | `Shift` | `B` | 触发短距离高速机动冲刺 |
| 战术模块 | `Q` | `RB` | 释放当前装备的战术模块 |
| 专属技能 / 采矿 | `E` | `Y` | 触发机甲专属技能；靠近矿脉长按采矿 |
| 快捷购弹 | `B` / `1` `2` `3` | `DPadUp` | 消耗全队经济补充弹药或维修护盾装甲 |
| 切换机甲 (S1/EP) | `U` | — | 在 S1 突击手与 EP 工程车之间快速切换 |
| 快速散热 | `R` | `X` | 紧急排出发射器热量 |
| 语音按键说话 | `V` | `LB` | 按住开启 WebRTC 语音麦 |
| 暂停 / 静音 | `Esc` 或 `P` / `M` | — | 打开暂停菜单 / 切换音频静音 |

## 技术栈

- **前端渲染与 UI**：React 19, TypeScript, Vite, Tailwind CSS v4, Three.js, `urdf-loader`, Lucide Icons
- **实时后端与联机**：Node.js, Express, `ws` (WebSocket), WebRTC 信令转发
- **测试校验**：Node 原生测试运行器（`tsx --test`）

## 项目结构

```text
.
├── index.html                  # 应用入口 HTML
├── server.ts                   # Express + WebSocket 权威游戏服务器与 API
├── public/
│   └── models/robomaster/      # RoboMaster S1 / EP 开源 URDF 与 COLLADA (.dae) 模型资源
├── src/
│   ├── App.tsx                 # 应用主状态与引擎/网络生命周期管理
│   ├── audio/soundEngine.ts    # Web Audio 合成音效引擎
│   ├── components/             # 主界面、HUD、军械库、大厅、设置、战绩及语言切换组件
│   ├── game/                   # Three.js 场景引擎、URDF 机甲装配、程序化贴图与建筑模型
│   ├── i18n/                   # 中英文词典与 LanguageContext
│   ├── net/clientSocket.ts     # WebSocket 客户端与 WebRTC 语音通道
│   └── shared/                 # 前后端共享类型、配置目录、物理/碰撞箱、匹配与反作弊及单元测试
└── package.json
```

## 本地运行与测试

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器（端口 3000）
```bash
npm run dev
```
启动后在浏览器访问 `http://localhost:3000`。

### 3. 运行单元测试
```bash
npx tsx --test src/shared/*.test.ts
```

### 4. 类型检查与生产构建
```bash
npm run lint
npm run build
```
